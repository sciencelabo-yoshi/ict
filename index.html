01｜出発点

授業中、こんなことを
思ったことはありませんか？

「こんなタイマーがほしい」

でも、ちょうどいいものが見つからない。

「この授業専用のツールがほしい」

既存サービスでは少しだけ使いにくい。

「生徒が操作できる教材がほしい」

アイデアはある。でも作り方が分からない。

「あと少しだけ変えたい」

文字、ボタン、動き、表示方法……。

02｜これまで
思いつく → 作れない → 諦める

「プログラミングができない」が、教師のアイデアを止めていた。

03｜生成AIで変わったこと
思いつく → AIに相談 → 作る → 試す → 直す → 公開する

必要なのは、最初からコードを書く力ではなく、
「何がほしいか」を言葉にする力。

04｜実演

「授業用のタイマーがほしい」

授業で使うカウントダウンタイマーを作ってください。 残り時間を大きく表示し、 5分・10分・15分のボタンをつけてください。 ブラウザだけで動くHTMLにしてください。
05｜一発で完成しなくていい

教師の意図を、対話で近づけていく

「文字をもっと大きく」

「黒板に映して見やすく」

「終了したら画面全体で知らせて」

「タブレットでも押しやすく」

生成AIは、教材を一緒に試作する相手になる。

11｜GitHubで公開する①

まず「置き場所」をつくる

1

右上の「＋」

GitHubにログインしたら、右上の＋をクリック。

2

New repository

新しいWeb教材の置き場所を作ります。

3

名前を入力

例：my-science-tool
この名前がURLの一部になります。

※画像はWord資料に挿入されていた元のスクリーンショットを直接使用しています。ログイン情報は掲載していません。

12｜GitHubで公開する②

HTMLファイルをアップロード

4

uploading an existing file

既に作ったファイルをアップロードする画面へ。

5

ドラッグ＆ドロップ

index.html と、必要な画像・フォルダなどを入れます。

6

Commit changes

アップロードした内容を確定します。

13｜GitHubで公開する③

Settings → Pages を開く

7

Settings

リポジトリ上部の「Settings」をクリック。

8

Pages

左側メニューから「Pages」を選びます。

ここがWeb公開の設定画面

コードを書く作業は、ここでは必要ありません。

14｜GitHubで公開する④

main / (root) を選んで Save

9

Branch：main

公開するデータの場所を指定。

10

Folder：/(root)

そのままルートフォルダを選択。

11

Save

あとは公開処理が終わるのを待ちます。

15｜GitHubで公開する⑤

12
